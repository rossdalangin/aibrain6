FAQ

Frequently Asked Questions

What makes Nexus AI different from ChatGPT Teams?

Unlike ChatGPT which is an isolated cloud chat box, Nexus AI Workforce is self-hosted natively inside your WordPress database. It offers multi-agent collaboration meetings, automated visual workflows, and can execute real site actions like writing draft posts or editing products.

Are my API keys and company data secure?

Yes, absolutely. All sensitive API keys are encrypted using robust AES-256-CTR encryption before storing. Your parsed RAG documents, message transcripts, and memory chunks remain secure on your own local server.

How does dynamic billing and license key activation work?

When a user purchases a plan, the server generates a cryptographically signed license key via secure HMAC-SHA256. Upon activating locally, your plugin checks this key remotely and securely expands your active workforce agent boundaries.
