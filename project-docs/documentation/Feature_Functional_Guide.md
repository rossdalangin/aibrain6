# Nexus AI Workforce: Functional & Feature Guide

This guide provides detailed instructions for every form, field, and section within the Nexus AI platform to ensure a premium user experience and optimal agent performance.

---

## 1. Executive Command Center (Overview)

### 1.0 The "AI Staff Room" (HQ)
- **High-Fidelity Interaction:** A dedicated full-screen chat interface designed for deep focus consultations with your AI workforce.
- **Agent Directory:** Quick-access sidebar to switch between specialists across all departments.
- **Real-time Status:** Live indicators showing which agents are currently "thinking" or "processing" delegated tasks.

### 1.1 The "System Integrity" Monitor
- **Real-time Diagnostics:** Instantly verify Encryption Engine, Database Table integrity (13/13 tables), and REST API connectivity.
- **Vibrant Analytics:** Interactive Chart.js visualizations for Token Consumption Trends and Workforce Efficiency.
- **Tactile Stream:** A live Activity Stream of strategic AI actions and meeting conclusions with biological ripple status indicators.

## 2. Workforce Hall (Employee Architecture)

### 2.1 The "Hire Agent" Persona Wizard
- **Name:** The human-readable name for the AI agent (e.g., "Sarah").
- **Position:** The specific professional role (e.g., "Senior SEO Strategist"). This heavily influences the agent's initial reasoning.
- **Department:** Categorize the agent for multi-agent meeting filtering.
- **Role Description (Identity):** *Instructions:* Write in the first person. "I am a growth-focused marketer with 10 years of experience in SaaS..."
- **Mission:** The primary objective of this role.
- **Strategic Objectives (KPIs):** Define success metrics. Agents reference these when weighing strategic options.

### 2.2 The AI Brain Builder (Advanced Config)
- **Temperature Slider (0.0 to 1.0):**
    - *0.2 - 0.4:* Professional, factual, low variance (CFO, Legal).
    - *0.7 - 0.9:* Creative, brainstorming, high variance (Copywriter, UX Designer).
- **Thinking Process (SWOT/First Principles):** Define the agent's logical framework.
- **Output Format:** Enforce Markdown, JSON, or specific bulleted lists for standardized reporting.
- **Few-Shot Examples:** Provide specific "Input -> Output" pairs to guide the AI's response style.
- **Negative Prompts:** Hard guardrails for what the agent must NEVER say or do.
- **Master Prompt Preview:** A real-time visual panel to verify the compiled system instructions before deployment.

## 3. Collaboration & Automation

### 3.1 Meeting Room (Consensus Engine)
- **Automatic Milestone Detection:** Real-time toast notifications when agents state a "DECISION" or "ACTION".
- **Reasoning Indicators:** Transparent "Reasoning" phase visualization to manage expectations during deep thinking.
- **Minutes Archive:** Searchable record of every collaboration with Markdown export capability.

### 3.2 Workflow Builder (Visual Orchestration)
- **Drag-and-Drop Canvas:** Seamlessly chain multiple specialized agents into a sequential business process.
- **Autonomous Delegation:** Agents can now delegate sub-tasks to other specialists via the `DelegateAction`.
- **Execution Trace:** Real-time log of state management across steps with downloadable audit logs.

---

## 4. Knowledge Base Manager (Enterprise RAG)
- **Agent Selector:** Switch between agents mid-conversation.
- **Context Pinning:** Pin specific Knowledge Base documents to the chat so the agent prioritizes them.
- **Logic Logs (Thinking Mode):** Click the "Brain" icon to expand the agent's internal reasoning process.

### 2.2 Meeting Room
- **Participant Selection:** Choose up to 5 agents. *Instructions:* For best results, include a "Moderator" (e.g., CEO) to synthesize the debate.
- **Consensus Mode:** Forces agents to vote on a final decision.
- **Meeting Minutes Export:** Automatically generates a Markdown summary of the discussion.

### 4.1 Document Ingestion
- **Multi-Format Support:** Native parsing for PDF, DOCX, and CSV (tabular data).
- **Web Crawler:** Index competitor or industry URLs to ground agent responses in real-world data.
- **Context Isolation:** Assign specific documents to individual agents or departments for granular data security.

## 5. Settings & Engagement

### 5.1 System Infrastructure
- **Encryption Status:** Shows a green shield if the key is stored with AES-256-CTR encryption.
- **Usage Limits:** Set monthly dollar caps to prevent overspending.

### 5.2 White Labeling (Agency Mode)
- **Global Brand Management:** Dynamically rebrand the WP Admin Menu title, Dashicon, and Platform Title.
- **Agency Logo:** Replace Nexus AI branding with a custom agency asset.
- **Premium Widget:** Enable/Disable the frontend chat widget and select the 'Public Agent' for customer-facing support.
- **Secure Client Portal:** Use the `[nexus_ai_portal]` shortcode on any WordPress page to provide a gated, high-end AI experience to your clients.
